# Aletheia Cold Cases

Case files from Project Aletheia (projectaletheia.org) — an independent
verification lab run by Bo Brothers. A cold case is an investigation that
ended honestly: killed by a better explanation, stalled by a broken
instrument, or too thin to call. We do not hide those endings and we do not
upgrade them into findings. Each case here names the exact missing piece
that would settle it. If you have that piece, the case can reopen.

Live cards with the plain-language version of every case:
https://projectaletheia.org/cold-cases

## What's in each folder

- CASE_FILE.md — the full case: what was on the table, how it died with the
  named defect, what still stands (with its claim ceiling), and precisely
  what would revive it, with hashed receipts to the underlying artifacts.
- VERIFICATION_RECEIPT_*.json — the independent review receipt that
  admitted the case to the public catalog.

## The rules these cases live under

A cold case is a question plus a data request, never a finding. Kills stay
killed: nothing here un-refutes anything, and any case that reopens goes
back through the lab's full preregistered verification pipeline as a new,
versioned test before a single conclusion changes. Every claim in every
file carries an explicit ceiling — the most it could ever prove.
